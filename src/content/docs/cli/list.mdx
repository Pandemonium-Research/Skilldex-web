# skillpm list

List the skills installed in each scope.

## Usage

```bash
skillpm list [--scope <scope>] [--json]
```

## Flags

| Flag | Default | Description |
|---|---|---|
| `-s, --scope <scope>` | all | Show one scope: `global`, `shared`, or `project` |
| `--json` | — | Output as JSON |

## Examples

```bash
# All scopes
skillpm list

# Only this project
skillpm list --scope project

# Machine-readable
skillpm list --json
```

## Example output

```text
global scope
  (no skills installed)

shared scope
  (no skills installed)

project scope
  pdf                            score: 100/100  source: community

1 skill(s) installed across 3 scope(s)
```

`source` is `community` for skills installed from the registry or GitHub and `local` for skills installed from a folder. A skill written against an older spec version is flagged with the `skillpm update` command that refreshes it.
