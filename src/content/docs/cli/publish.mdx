# skillpm publish

Register a skill with the Skilldex registry. The registry does not store an upload: it records the skill's GitHub location, fetches `SKILL.md` from there, and scores it.

## Usage

```bash
skillpm publish [--source-url <url>] [--tags <tags>] [--json]
```

Run it from the skill's folder. The skill's name comes from the `name` field in its `SKILL.md`.

## Flags

| Flag | Description |
|---|---|
| `--source-url <url>` | GitHub URL of the skill. Detected from the folder's git remote if omitted |
| `--tags <tags>` | Comma-separated tags, e.g. `pdf,documents` |
| `--json` | Output the result as JSON |

## Authentication

Publishing needs a token. Sign in with GitHub at the registry's `/auth/github` page — `skillpm publish` prints the exact URL when no token is set — then store it:

```bash
skillpm config set token <token>
```

The `SKILLDEX_TOKEN` environment variable works too.

## Examples

```bash
# Publish the skill in the current folder
skillpm publish --tags pdf,documents

# The git remote is not the skill's home
skillpm publish --source-url https://github.com/you/skills/tree/main/my-skill
```

The skill must be pushed to GitHub first: the registry reads it from there, not from your disk. See [Publishing to the registry](/docs/publishing/publishing-to-registry).
