# skillpm uninstall

Remove a skill from a scope, along with the links made into agent directories.

## Usage

```bash
skillpm uninstall <skill-name> [--scope <scope>] [--json]
```

Use the skill's installed name — `pdf`, not `anthropics/pdf`. `skillpm list` shows installed names.

## Flags

| Flag | Default | Description |
|---|---|---|
| `-s, --scope <scope>` | `project` | Scope to remove from: `global`, `shared`, or `project` |
| `--json` | — | Output the result as JSON |

## Examples

```bash
# Remove from the current project
skillpm uninstall pdf

# Remove from global scope
skillpm uninstall pdf --scope global
```

```text
✔ Uninstalled "pdf" from project scope
```

Exits with code `1` if the skill is not installed at that scope.
