# skillpm validate

Check a skill folder against the skill format specification and print a compiler-style report with its format conformance score.

## Usage

```bash
skillpm validate [path] [--json]
```

`path` defaults to the current directory.

## Flags

| Flag | Description |
|---|---|
| `--json` | Output the full result as JSON |

## Examples

```bash
skillpm validate
skillpm validate ./my-skill
skillpm validate ./my-skill --json
```

## Example output

```text

  pass    name field present
  pass    name is kebab-case and uses no reserved words

  pass    description is within the character limit and free of XML tags
  pass    SKILL.md line count OK (38 lines)
  pass    Folder structure matches convention
  warn    README.md should not be inside the skill folder — put docs in SKILL.md or references/
  pass    All referenced resources exist
  pass    Bundled resources in correct subdirectories

Score breakdown:

  description-format    11/11
  line-count             7/7
  allowed-subdirs        4/4

Format conformance score: 96/100
```

See [Quality scoring](/docs/concepts/quality-scoring) for what each check measures.

## Exit codes

| Code | Meaning |
|---|---|
| `0` | No errors (warnings are allowed) |
| `1` | At least one error |

To validate a skillset, use [`skillpm skillset validate`](/docs/cli/skillset).
