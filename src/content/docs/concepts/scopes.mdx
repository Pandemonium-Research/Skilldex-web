# Scopes

Every skill is installed into one of three scopes. The scope decides where the files live and which agents see them.

| Scope | Stored in | Linked into | Use it for |
|---|---|---|---|
| `project` (default) | `<project>/.skilldex/skills/` | `<project>/.agents/skills/`, `<project>/.claude/skills/` | Skills one project needs |
| `shared` | `~/.skilldex/shared/skills/` | `~/.agents/skills/`, `~/.claude/skills/` | Skills you share across a set of projects |
| `global` | `~/.skilldex/global/skills/` | `~/.agents/skills/`, `~/.claude/skills/` | Skills you want everywhere |

```bash
skillpm install anthropics/pdf                   # project
skillpm install anthropics/pdf --scope shared
skillpm install anthropics/pdf --scope global
```

Change the default with `skillpm config set defaultScope <scope>`.

## Linking into agents

Agents read skills from their own directories, not from `.skilldex/`. After installing, `skillpm` links the skill into:

- `.agents/skills/` — read by Codex, Gemini CLI, Cursor, Copilot, OpenCode, and others
- `.claude/skills/` — read by Claude Code, and also by Cursor, Copilot, Cline, and others
- Qwen Code's, Cline's, and Antigravity's own directories, when those agents are installed

Agents read at two levels, the project and your home directory, so `shared` and `global` both link into your home directory. Links are symlinks where the system allows them and copies otherwise. Pass `--no-bridge` to skip linking.

## Where the project is

For `project` scope, `skillpm` walks up from the current directory to the nearest folder containing `.git/` or `package.json`, and puts `.skilldex/` there — next to `.git/`. With neither, it uses the current directory.

## Same name, several scopes

Each scope is independent: the same skill can be installed in more than one. Installing a skill that is already in the same scope fails unless you pass `--force`.

## Committing project skills

Each scope keeps a manifest, `skilldex.json` — see [The manifest](/docs/concepts/manifest). For a project, you can commit `.skilldex/` so everyone who clones the repository has the skills, or ignore it and have each person install what they need.
