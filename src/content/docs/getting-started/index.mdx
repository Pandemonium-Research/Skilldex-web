# What is Skilldex

Skilldex is a package manager for agent skills. It lets you search, install, validate, and publish skills — folders of instructions and resources, built around a `SKILL.md` file, that teach a coding agent how to do something specific.

Think of it like npm, but for agent capabilities instead of JavaScript libraries.

## The problem it solves

Skills are powerful, but they live scattered across individual repositories with no standard way to find or reuse them. A good skill written for one project is hard to use in another, and a skill found on GitHub says nothing about whether it follows the format agents expect.

Skilldex fixes this with three things:

1. **A CLI** (`skillpm`, or `spm` for short) for installing and managing skills
2. **A registry** of skills you can search from the terminal or [the web](/registry)
3. **A validator** that scores every skill against the skill format specification

## Key concepts

### Skills

A skill is a directory with a `SKILL.md` at its root: YAML frontmatter with a `name` and a `description`, followed by the instructions the agent follows. It can also carry `scripts/`, `references/`, and `assets/`. See [Skill format](/docs/concepts/skill-format).

Skills are installed into one of three scopes — **project** (the default), **shared**, or **global** — and linked into the directories your agents read, so Claude Code, Codex, Cursor, and other agents pick them up. See [Scopes](/docs/concepts/scopes).

### The registry

The registry indexes skills published on GitHub. Names are only unique within an owner, so the registry addresses a skill as `owner/name`:

```bash
skillpm install anthropics/pdf
```

The CLI looks the skill up, clones it from its source repository, validates it, and installs it.

### Quality scores

Every skill has a **format conformance score** (0–100): how closely it follows the skill format specification. It measures format, not usefulness. See [Quality scoring](/docs/concepts/quality-scoring).

### Skillsets

A skillset is a named bundle of skills installed together, with shared conventions its members are checked against. See [`skillpm skillset`](/docs/cli/skillset).
