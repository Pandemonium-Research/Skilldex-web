# Quick reference

The most common `skillpm` commands at a glance. `spm` works anywhere `skillpm` does.

## Find and install

```bash
skillpm search <query>                     # search the registry
skillpm install <owner>/<name>             # install from the registry
skillpm install ./path/to/skill            # install from a local folder
skillpm install git+https://github.com/<user>/<repo>   # install from GitHub
skillpm install <owner>/<name> --scope global
```

## Manage installed skills

```bash
skillpm list                               # all scopes
skillpm list --scope project
skillpm update <name>                      # re-fetch from its source
skillpm update --all
skillpm uninstall <name>
```

## Write and publish

```bash
skillpm init my-skill                      # scaffold a SKILL.md
skillpm validate ./my-skill                # score it against the spec
skillpm publish                            # from the skill's folder
```

## Skillsets

```bash
skillpm skillset search <query>
skillpm skillset install <name>
skillpm skillset list
```

## Suggestions and configuration

```bash
skillpm suggest                            # skills for the current project
skillpm config list                        # valid config keys
skillpm config set defaultScope global
```

## Help and version

```bash
skillpm --help
skillpm <command> --help
skillpm --version
```

Every command that reports something also takes `--json` for scripting.
